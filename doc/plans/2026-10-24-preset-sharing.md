# 快捷指令 JSON 分享实施计划

**目标**：在快捷指令管理器分享当前指令草稿，并把收到的 JSON 保存为独立新指令。

**架构**：纯分享服务负责固定版本格式、白名单字段及输入校验；管理器复用已有剪贴板、JSON 文件服务和 Store Action，不扩展原生权限或数据库结构。

## 范围与实现

1. `src/services/presetShareService.ts`：序列化和解析 `{ kind: "ai-canvas-preset", version: 1, preset: ... }`。保留基础模板、高级参数/步骤、参考来源、执行方式、模型和尺寸引用；不传递原记录 ID、文件夹归属、运行状态或连接凭据。导入重建指令、参数和步骤 ID。
2. `PresetManager.tsx`：分享当前编辑草稿，提供复制 JSON 和导出文件；导入后调用 `addUserPreset`，切换相应类型并选中新记录，不覆盖已有内容、不自动运行。
3. `PresetImportDialog.tsx`：复用 UI Kit 与 `ModalOverlay`，支持粘贴 JSON 或选择文件；校验/保存失败保留输入，忙碌时阻止重复提交和关闭。英日韩文案放在既有 `nodes.ts`。
4. 复用 `clipboardService.copyText` 与 `fileService.readJsonTextFile/exportJsonTextFile`；JSON 上限 8 MiB、文件严格 UTF-8、桌面原生另存为和 Web 下载行为不另造实现。
5. `tests/services/presetShareService.test.ts`：补充基本/高级往返、可选字段、新身份、版本与类型拒绝、坏缩略图和体积边界的回归源码。默认不运行测试、lint、类型检查、构建或应用。

## 边界

- 仅分享单条指令；模型连接、工作流文件和参考素材仍由接收方配置。JSON 只携带相关名称/ID 引用。
- 导入是外部数据，按白名单构造新对象；未知字段不进入持久化，错误不回显原 JSON。
- 缩略图只接受受限的内嵌位图；不接受 SVG、外部链接或本地文件路径。拒绝非法枚举、超限集合/字符串、非有限数值、重复/特殊参数键和无效高级模板。
- 取消文件选择/另存为不创建指令、不显示成功；复制或导出不会隐式保存编辑草稿。
