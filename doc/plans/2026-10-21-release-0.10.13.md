# v0.10.13 与视频复刻 v0.2.1 发布计划

执行日期：2026-10-21。宿主基线为正式标签 `v0.10.12`，源码准备基线 `b6136477`；插件基线 `video-replica-v0.2.0`，源码准备基线 `e497a25`。主题「引用预览与逐镜制作」。

## 范围与边界

- 引用胶囊双击全屏、来源信息与连续返回，节点、分镜、角色/资源和助手统一展示；稳定镜头引用实时读取本镜内容与时长。
- 视频复刻用指定角色图改写外观，原视频联系表提供动作与构图；仅保留控制视频、音频、分段生成及完整视频，按分段排列。重开窗口恢复界面和进度，已终止任务显式重新开始，查询预算与普通操作分开。
- 资源增量展示、分组色板/背景、macOS 输入分流和窗口拖动、ComfyUI 安装表单降级。
- 宿主版本、锁文件、四语言 README、官网/手册、Release 正文和工作流同步到 0.10.13；插件版本 0.2.1、最低宿主 0.10.13，市场绑定新稳定标签。先升级宿主，再更新插件。
- 修复既有远端 CI 的引用预览类型错误：节点与资产悬浮内容共用明确类型，避免推断联合类型互相锁死；独立窗口输入范围校验不再错误收窄为 `never`，实际权限和显示行为不变。拒绝请求测试按各响应完成后再继续，保留四类拒绝及未读取图像的断言，避免原生模块替身并发冷导入问题；不放宽类型、测试、安全或签名门禁。
- 沿用现有依赖、schema v22、私有凭据及插件租约。标准 Windows、Apple Silicon Mac、Linux 与后续 Windows Legacy 沿用既有矩阵，不增加 Intel Mac 安装包、不读取本机签名私钥、不调用付费模型。

## 待桌面验收

1. 升级宿主后再安装插件 0.2.1，完成可信 Python 原生确认。新任务选取明显不同的角色图，核对逐镜提示词和实际成片的面容、发型、服装；关闭重开窗口恢复同一任务，失败后重新选引用再开始，未知提交不得自动重投。
2. 普通画布与父分组内复刻至少两段，检查控制视频/音频/生成片段及完整成片对齐，不出现额外分镜/说明节点；已有用户节点不移动。长时间查询不耗尽普通操作额度。
3. 节点和助手引用胶囊双击查看文本/图像/视频/音频和指定镜头，继续打开嵌套引用并返回；重排分镜后生成仍读取原指定镜头，旧静态提示词不自动迁移。
4. 资源扫描时切项目或关闭面板，不出现过期卡片写回；回归分组色板外部关闭、macOS 鼠标/触控板和弹窗拖动，以及 ComfyUI 安装信息读取失败后的表单与重试。
5. 各平台从上一版安装/升级，核对版本和自动更新签名；Legacy 无本地 ONNX/自动更新，Mac 首次下载的 Gatekeeper 行为仍须真实机器验证。

回退使用上一正式版本或停用插件；发布标签不覆盖、不移动，发布缺陷另发补丁。不删除用户数据、凭据或历史节点。
