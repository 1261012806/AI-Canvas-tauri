# v0.10.9 发布计划

执行日期：2026-10-16。以正式版 v0.10.8 为基线，发布主题为「重要优化：多连线画布性能」。

## 范围

- 连线视口绘制、连续倍率裁剪与缓存、交互刷新、小地图点击定位和连线隐藏切换。
- 剧集归档完整性、macOS 最大化及两素材扇形排列修复。
- 归档设置读取增加对象形状校验，修复发布类型检查阻断；保持现有合法素材引用。
- 归档回滚测试桩补齐异步目录删除返回值；33 项归档测试通过，不改变生产清理逻辑。
- 删除三种语言中已无调用的旧连线切换提示词条，沿用直角、曲线、隐藏的新提示。
- 同步版本、更新说明、多语言徽章、官网与说明书。保持 IndexedDB v22 和现有安全边界。

## 发布状态

- 版本与公告已准备；隔离源码副本的 npm ci、ESLint、应用与测试类型检查、cargo check --lib 已通过。全量测试与生产构建进行中，远端 CI、多平台构建、签名与正式公开待完成。
- 此前连线定向测试 11 个文件 / 156 项通过；用户反馈原卡顿场景已可用。未量化帧率，未完成全平台桌面矩阵验收。

## 验收与回滚

1. 桌面端打开多连线项目，连续缩放并拖拽，检查曲线、直角、隐藏切换以及连线选择、悬停。
2. 点击小地图不同位置，检查视野居中且倍率不变；回归锁定和手动导航。
3. 导出并重新导入多分集剧集，逐集检查画布、配置和素材；回归 macOS 最大化。
4. 各平台安装与从上一版升级、更新签名与 latest.json 待实机验收。

标签推送前可撤销版本准备提交；标签推送后不覆盖标签，修复另发补丁。
