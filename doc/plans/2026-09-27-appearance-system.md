# 全局外观系统实施计划

## 范围

- 设置页新增“外观”，统一管理页面配色、主题模式、画布、节点、连接线、连接手柄与动效。
- 外观以完整快照保存；内置深色、浅色、跟随系统入口，以及太阳系、磨砂暖光完整预设。
- 自定义预设持久化到 IndexedDB，支持 `.aicanvas-theme` JSON 导入与导出。
- 主窗口、聊天窗口、资源搜索窗口、视频编辑器窗口和 UI Kit 窗口统一通过外观运行时应用 CSS 变量。
- 旧版 `theme/canvasBackground/customBackground*` 仅作为一次性迁移输入，常规页不再展示旧画布背景控件。

## 按钮外观验收（2026-10-13）

- 已实现，待用户验证。提交钩子已通过本次改动文件的定向 ESLint；Vitest、类型检查与桌面实机验收尚未执行。
- 前置：Tauri 桌面端进入“设置 → 外观 → 按钮外观”；从“关于”连续点击 logo 4 次打开 UI Kit，在按钮分区保持“跟随外观”。
- 点击普通/主按钮各项颜色的色块选择自定义颜色，检查设置页真实按钮预览与 UI Kit 同步；悬停时使用对应悬停背景，文字与边框分别生效。普通按钮配色也适用于公用次级按钮；危险、链接、节点类型按钮保留语义配色。
- 将圆角与边框宽度设为 0，应得到直角、无边框按钮；调整为非零值后恢复。小号/大号圆角按比例变化，禁用、选中与键盘焦点状态仍可辨识。
- 点击单项“跟随”，再修改主题色，主按钮跟随主题；点击“恢复按钮默认”应恢复默认尺寸及全部自动配色。普通/次级按钮恢复各自原有主题层次。
- 保存为自定义预设，切换预设后重新加载，以及导出再导入主题，按钮配置应保留；导入缺少按钮字段的旧主题应使用默认值。系统模式同步默认明暗配色时保留按钮自定义配置。
- UI Kit 切换暗色/浅色预览，再返回“跟随外观”，按钮配置应保持；关闭重开后仍使用当前配置。
- 定向自动化入口（仓库根目录）：`npx vitest run tests/services/appearance.test.ts tests/services/appearanceWindowSync.test.ts tests/components/appearanceSettings.test.tsx`；实际悬停、焦点、主题切换与持久化仍需桌面端验收。
