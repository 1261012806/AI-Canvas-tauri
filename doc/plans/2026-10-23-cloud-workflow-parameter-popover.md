# 云工作流参数浮层

目标：将节点提示词下方的云工作流内嵌表单移到输入栏底部参数浮层，沿用视频参数的视觉结构，并按工作流声明选择控件。

架构：`PromptPanel` 负责选择当前工作流，独立浮层复用既有字段组件和 UI Kit。参数仍通过 `onWorkflowInputsChange` 写入节点，保留 RunningHub 的编码字段键及通用工作流的 `workflow::` 键。RunningHub 定义补充可选控件元数据，原工作流身份、请求映射及凭据不变。技术栈为 React、TypeScript 和既有 CSS token，无新增依赖。

## 实施范围与状态

- 已实现：RunningHub、声明式工作流 API 使用底部参数浮层；旧版工作流 API 的种子并入既有视频参数浮层，普通模型和本地 ComfyUI 保持原入口。
- 已实现：比例枚举使用多列选项；分辨率与时长仅使用数值或离散选项滑块及刻度，移除下方数值输入与区间编辑入口，保留原值显示。其他枚举按数量与长度显示分段按钮或下拉，布尔值显示双选，普通数字和短文本仍使用输入框，多行文本使用文本域。
- 已实现：滑块当前值与「恢复默认」并入标题行，不额外占一行；标题行保持最小控件高度，沿用 UI Kit 字段间距与原时长控件的滑轨/刻度间距，避免出现恢复按钮时上下跳动。深浅主题及间距观感待桌面验收。
- 已实现：新浮层优先上方展示，空间不足翻转并限制到视口；内部滚动、下拉菜单、Esc、焦点返回及生成期间只读。画布交互时收起浮层，浮层内键盘不触发画布编辑快捷键，保留保存与开发者工具入口；滑块回写复用连续编辑历史。
- 待用户验收：本次未运行自动化测试、类型检查、构建、桌面操作或真实生成；提交阶段按仓库规则由钩子执行定向 ESLint。

## 参数边界

- 数值分辨率和时长缺少边界声明时，按用户确认的文档范围显示：时长 2–30 秒（默认步长 1）、分辨率 0.2–4（默认步长 0.1），不随初始值变化，不提供区间编辑。明确的工作流范围/步长及离散选项优先，不覆盖其他工作流的真实声明。单侧声明与默认区间不相交时仍保留已知边界的选择入口。
- RunningHub 仅在实际收到类型匹配的 `INT/FLOAT/STRING` tuple 时提取有限的 `min/max`、正数 `step` 和布尔 `multiline`；旧定义和 API graph 缺少这些元数据时沿用兼容展示。最小/最大值进入参数校验，步长仅控制 UI 精度，不作为倍数约束。
- `16:9 (Widescreen)` 等枚举保留原值；数值分辨率 `1.5` 不改成其他档位。`0`、`false`、未填写和默认值分别处理，打开浮层不会产生显式覆盖。
- 原值不在滑块区间或步进刻度时保留数值显示，不自动吸附；用户可选择刻度后拖动。固定范围只有一个值时也保留可选刻度，避免删除输入框后无法填写。步长不等于平台强制限制，非倍数值仍按既有执行规则校验。
- RunningHub 主提示词与参考素材在节点对话框编辑，参数浮层不重复展示正文或「提示词与参考素材」区。导入编辑器仍用于核对默认值和来源映射。
- 唯一且明确的 `prompt/positive_prompt` 或主提示词标签兼容绑定到本轮正文；负面、系统、风格、优化等辅助提示词、枚举和多候选不自动改绑。显式选择来源后用可选 `sourceExplicit` 保留决定，旧节点残留的主提示词覆盖值不再代替节点正文。
- 媒体绑定按本轮参考素材的类型和索引读取，不读取隐藏的旧 `workflowInputs` 媒体覆盖，也不回落导入样例文件。可选空槽传空串，必填缺少素材在上传前提示；普通标量仍可用原编码键覆盖。RH 专属上传和官方依据见 [RunningHub 平台计划](./2026-09-08-runninghub-platform.md#本轮节点输入与官方上传)。
- 仅按字段名与标签识别比例、分辨率、时长，用于排版和底部摘要；未识别字段仍可编辑，重复语义字段不合并。

## 桌面验收（待用户执行）

1. 在 Tauri 桌面端选择已有 RunningHub 视频工作流，打开节点输入框；提示词下方不再出现大表单，底部参数入口可打开浮层。核对可调字段与原默认值；主提示词和参考素材只在节点输入框编辑，浮层无重复正文和素材说明区。
2. 修改比例枚举、数值分辨率、时长、布尔值和文本，关闭后重开并保存项目，确认值保留；撤销/重做和重启读取已有节点均应可用。仅打开和关闭浮层不应新增参数覆盖。
3. 通用工作流 API v2 分别准备比例枚举、字符串分辨率档位、整数时长范围及无范围数值分辨率的定义；预期比例为多列选项，分辨率档位按原值拖动。无范围声明时，时长端点为 2/30，分辨率端点为 0.2/4，二者下方均无数值输入或「调整滑块区间」；更换当前值并重开时端点不变。明确声明的其他范围、固定单值和离散档位仍正确显示，普通数字字段仍可输入。
4. 核对旧版工作流 API 的种子及既有视频参数均可设置；切换工作流不串用参数，生成期间可查看参数但不能修改，提示词和媒体引用仍通过原入口编辑。
5. 深浅主题、窄窗口、靠近屏幕边缘时，浮层和下拉不被截断，内容可滚动。滑块当前值应在标题右侧，标题与滑轨之间没有独立数值行或额外下边距；拖动后显示「恢复默认」时滑轨不应跳位。用键盘打开、Tab 编辑，Esc 先关闭下拉，再关闭参数浮层并回焦点，节点对话框保留；点击外部正常收起。
6. 浮层或选项按钮聚焦时，数字键、Delete 和撤销不应操作底层画布；Ctrl/Cmd/Alt+S 仍可保存。滚轮移动或缩放画布应收起浮层，重新打开位置应贴近入口；拖动一次时长滑块并收起后，撤销应恢复拖动前的值。普通文本或数字字段清空后仍能输入，未填写或仅打开浮层时不产生显式覆盖。

7. 通过 RunningHub 官方定义或 JSON 导入类型匹配的数值 tuple，核对分辨率和时长读取实际范围/步长；超声明边界应在提交前拒绝，合法的非步长倍数不会仅因步长被拒绝。`multiline` 字符串切换为提示词绑定后仍能保存；旧 API graph、LIST 枚举和原有已保存工作流仍能打开。
