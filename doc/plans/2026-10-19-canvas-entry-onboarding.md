# 首次进入画布入口引导

目标：第一次打开真实画布时，以四步引导说明顶部项目设置、右侧操作记录、剧集入口和文件保存位置。

## 实施顺序

1. 在现有 UI slice 增加入口引导开关；App 等项目首帧就绪、发行提醒关闭后触发。使用独立版本化本地标记，完成或跳过后不再自动显示，启动页与加载遮罩期间不展示。
2. 给 SessionProjectTabs、HistoryTimelinePanel、SeriesRail 和 FileAppSettings 的实际入口添加定位标记；引导通过 body Portal 和既有 useDialogFocus 展示，复用 UI Kit，实时响应窗口大小和设置内容尺寸，不扫描节点或复制假界面。
3. 最后一步打开既有“文件与应用”设置并定位文件保存区域。引导只展示说明；“开始设置”退出引导并留在该页，“稍后设置”关闭引导打开的设置。此前步骤不执行目录选择或修改配置。
4. 原 OnboardingDialog 保留为可选的操作技巧，从帮助中心提供重看入口；补充布局边界回归与手动验收，不自动运行测试或提交。

## 边界

- 本地只记已看标记，不保存目录、节点数据或项目内容。旧版欢迎说明的已看标记不替代本次入口引导。
- Esc、关闭、跳过均结束本次引导；关闭后焦点回到现有界面。设置仅在引导主动打开时由引导收回。
- 定位元素缺失时显示居中说明，不伪造入口或阻塞后续步骤。引导期间遮罩阻止误操作，支持键盘、明暗主题和窄窗口。
- 引导结束后的文件位置修改仍由现有设置与原生目录选择流程处理。

## 状态与验收

已实现，本次未运行测试，待用户验收。文案与引导组件集中在 `OnboardingDialog.tsx`，分别按需加载入口引导与操作技巧；布局计算位于 `canvasGuideLayout.ts`，弹层复用 UI Kit 与 `useDialogFocus`。定位依赖实际入口标记，仅观察当前目标及说明卡尺寸；设置懒加载完成后才跟随入场位置，卸载时清理监听与引导主动打开的设置。

Tauri 桌面验收：

1. 使用首次启动状态进入项目列表：仅显示现有发行提醒；打开或新建画布，待首帧就绪后出现入口引导。
2. 依次下一步，核对高亮分别指向顶部短线、右侧上方操作记录入口、右侧中间剧集入口，文字与真实操作一致。最后一步打开“设置 → 文件与应用”，高亮文件保存位置；检查默认位置及当前项目目录可见，未自动弹出文件选择或改变路径。
3. “开始设置”留下文件设置页，用户可主动选择目录；“稍后设置”、Esc、关闭、跳过均结束引导。重新打开项目及重启应用不重复自动弹出；从帮助中心可重看。
4. 回归上一步、操作技巧、帮助中心、项目切换/退出、设置已打开、UI 懒加载较慢，以及深浅主题、窄窗口、缩放、Tab/Shift+Tab、减少动态效果。目标不可见时说明卡仍可继续，卡片不能跑出窗口。

定向布局回归（仓库根目录，供用户执行）：`npx vitest run tests/utils/canvasGuideLayout.test.ts`，覆盖顶部、右上边缘、底部避让、目标缺失和窄窗口。引导内容、首次触发和设置交接仍需以上桌面验收；本次未执行浏览器、桌面、测试、lint、类型检查或构建。
