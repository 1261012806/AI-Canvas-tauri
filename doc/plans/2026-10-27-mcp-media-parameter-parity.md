## 范围与边界

- MCP 厂商草稿按精确型号声明图片质量、背景、像素尺寸表及视频自动时长、操作级能力和素材数量；旧连接的部分能力更新保留未修改字段，再检查完整合同。动态尺寸表需要有界校验，不能只依赖工具 schema。
- 媒体能力查询只返回所选模型可公开的能力，不返回协议、连接地址或凭据；图片质量／背景和视频帧率／音轨／自动时长贯通工具、生成、画布及对话结果。空背景表示接口默认，`false` 保留为明确关闭；无效或未声明参数不能静默发送到其他模型。
- 异步原任务只增加可选的纯参数快照，恢复仍使用既有任务身份；旧记录兼容，不重新提交生成。图片的尺寸、比例和已声明的质量／背景默认值在提交前锁定；明确选择接口默认背景时仍保留空值。快照只允许有限参数，过滤明显的地址、路径和常见密钥格式，不存提示词或素材正文；不依靠格式规则识别任意无前缀密钥。
- 自定义视频协议校验包括按操作声明的比例；RelayOnAPI C2 保留官网要求的“图片1／音频1”，C1 不变。A 渠道首尾帧需要独立 multipart 合同及素材限制，文档尚不充分，本批继续拦截。

## 待用户验收

1. 在桌面端重新加载 MCP 工具目录后，查看普通图片和视频模型能力；确认只显示对应型号声明的质量、背景、帧率和音轨，不显示地址或凭据。配置草稿分别试合法和非法的尺寸表、默认值、操作级比例及自动时长；更新一个能力时原比例与分辨率应保留。
2. 用 MCP 创建图片节点，设置质量和透明背景，再改为空背景；查询与重开后应显示相同值。创建视频节点，选择已声明的自动时长、帧率并关闭音轨，查询与重开应保留 `false`。未声明的负数自动时长、跨类型参数应在写入或提交前报错。
3. 经用户自行决定的付费验收，生成一张透明图片和一个视频，检查实际请求参数、文件 alpha 与最终节点；中断异步视频后继续取回原任务，确认无重复提交、结果转画布保留参数。
4. 使用自定义视频模型测试操作级多比例：固定比例协议应被拒绝，动态比例映射允许保存。万象 C1 和 C2 分别使用同一组引用，确认最终提示词编号符合各自文档；C2 真实平台兼容性尚待验收。
