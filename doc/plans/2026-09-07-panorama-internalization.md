# 全景源码内置

归属：[画布与项目](../画布与项目模块.md)。本计划是当前全景实现、来源和验收边界的唯一专项入口；已合并 2026-07-22 的旧外部包集成设计与完成记录。2026-10-28 的文档整理未重新运行以下历史验收。

## 范围与行为

将此前锁定在 `c743a39041b8049e1edfa3041311ab996aa1ff8f` 的 XiaoLuo-Panorama 核心、全屏组件和相关样式迁入项目，移除 Git 依赖及其独立库构建；保留已有 `pannellum@2.5.7` 并改为直接依赖。

- 源码：`src/components/nodes/panorama/internal/`；领域类型：`src/types/panorama.ts`。
- 样式：`src/styles/panorama-core.css`、`panorama-viewer.css`，通过 `src/index.css` 统一加载；保留全景 JS 懒加载。
- 沿用节点预览、全屏漫游、缩放、视觉矫正、比例截图和建筑截图；移除宿主未使用的在线字体、上游代理地址与 Tailwind 4 构建指令，适配项目主题。
- `PanoramaNode` 继续负责文件落盘、图片节点创建、历史与派生结果防护，不改项目数据格式或 Tauri 权限。
- 关闭全屏会取消未开始的截图任务；截图解码后、调用宿主前检查实例仍有效。核心卸载后不再转发迟到事件，并释放 ResizeObserver 和渲染器。
- Apache-2.0 许可证及修改来源随 `public/licenses/` 分发；来源标记仅用于归属说明，不再是运行或构建依赖。

## 接口与宿主边界

核心通过元素引用管理 Pannellum 实例，负责等距柱状图、拖拽缩放、视角和截图；不使用固定 DOM ID，不修改全局 Canvas API，不自行调用上游代理。全屏查看器组合核心并提供漫游、视觉矫正、重置、即时或比例截图；实际回调、截图结果和 imperative API 以 [panorama.ts](../../src/types/panorama.ts) 为准。

`imageUrl` 与主题由宿主传入，加载失败通过回调显示可恢复状态。核心截图返回画面，比例截图附带裁切信息，宿主沿用项目文件保存、图片节点创建和单次历史提交；文件权限、项目切换防护及新节点创建不下沉到通用查看器。URL 变化或卸载时释放实例、事件和动画任务，禁止旧实例回调发布迟到结果。

## 风险与回滚

主要风险为上游样式迁入后的主题覆盖差异，以及不同 WebView/GPU 对 WebGL 的支持。应用不再依赖原仓库，但渲染器仍要求 WebGL。

回滚仅撤销本次组件、类型、CSS、依赖清单及对应测试/文档变更，恢复旧 Git 依赖即可；无数据迁移、权限修改或用户资源删除。
