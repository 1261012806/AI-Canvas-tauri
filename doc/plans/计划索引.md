## 维护与恢复

- 一项专项维护一份文件；发现与进度写入同一份必要摘要，不再新增 `findings.md`、`progress.md` 副本。长期职责、接口与产品说明回到模块文档，架构取舍放 [ADR](../adr/)。
- 未完成验收、独有协议、安全边界和回退依据继续保留，不按日期批量删除。旧版发版检查合并到[发布记录](../发布记录.md)；[v0.10.18「项目资产云同步与万象分组」发布准备](./2026-10-27-release-0.10.18.md)记录当前范围与门禁，尚未据此确认公开；[v0.10.17](./2026-10-25-release-0.10.17.md)、[v0.10.16](./2026-10-24-release-0.10.16.md)、[v0.10.15](./2026-10-23-release-0.10.15.md)和[v0.10.14](./2026-10-22-release-0.10.14.md)保留各自独立证据。
- `doc/history/` 保持冻结。历史正文里旧路径是当时的记录；删除的旧文件可从 Git 查看：`git log --all -- doc/plans/旧文件名.md`，再用 `git show 提交号:doc/plans/旧文件名.md` 读取。
