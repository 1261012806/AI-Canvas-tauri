# 全局创作资产实施计划

日期：2026-10-23。状态：代码已实现，待用户验收；提交门禁使用改动文件定向 ESLint，测试、类型检查、构建与桌面验收未执行。

## 目标与边界

- 在资源库「全局资产」中增加人物、场景、道具三个固定分类，与真实文件夹分开导航。
- 人物使用现有全局角色 ID、参考图、声音与动作，不复制为第二套人物记录。
- 场景、道具增加全局元数据持久化；图片先保存为全局受管素材，再保存稳定素材身份，剥离项目节点依赖。
- 保留旧全局角色及 `global/` 引用协议；普通导入文件和外部目录不自动分类或迁移。
- 同步提示词候选、解析与预览、库引用优先转换，以及 Agent/MCP 的查询、修改、删除与绑图。
- 资产卡片删除保留共用媒体文件；文件删除仍由既有文件菜单处理。

## 已实现范围

1. 数据：扩展领域主图身份，增加全局场景/道具存储、媒体服务与 Store Action，补齐媒体目录迁移覆盖。保留 `globalCharacters` 的唯一人物记录。
2. 引用：扩展统一全局查找和惰性加载，贯通 `@` 候选、文本/媒体解析、悬浮预览、插件目录、视频批次指纹及 MCP 库引用优先规则。
3. 工具：按全局/项目作用域分派三类资产 CRUD 与图片绑定；人物声音、动作沿用既有逻辑；保留 Policy 与画布 revision、取消保护。
4. 界面：增加固定分类导航，复用创作卡片与角色库编辑；支持新增、编辑、上传/绑定图片和现有文件创建创作资产。人物声音、动作作为资源库上的弹层打开，保留原分类与展示模式；退出角色管理后返回原资源库，明确定位画布时关闭资源库。复用 UI Kit，保持主题与键盘交互。
5. 收敛：已补充持久化、作用域、旧库升级、冷引用、MCP 路由及异步失效回归用例，更新角色与短剧资产、存储模块说明。用例、类型检查、构建与桌面验收未执行；提交时复用 `pre-commit` 对改动文件执行定向 ESLint。

## 验收入口（由用户执行）

以 Tauri 桌面为主：从启动页打开资源库，核对三类入口和旧全局角色；新增全局人物并绑定声音、动作，新增场景与道具并上传/绑定图片；关闭重开、切换项目仍可见。既有文件创建卡片后文件列表与目录不变。

点击全局人物卡片主体（图片、名称、简介或空白处），或用 Tab 聚焦卡片后按 Enter/空格，应直接打开对应角色界面；声音、动作按钮分别打开对应区域，复制、编辑、上传、删除按钮不触发主体打开。资源库应保留在背景，不露出启动页；关闭按钮或 Esc 只关闭当前弹层，退出角色管理后回到原分类与滚动位置。全局三类卡片均不显示“解绑图”，有图时仍可上传替换，无图时保留绑图入口；项目创作资产原有绑图、解绑不变。分别回归整页、弹窗与抽屉模式，以及从角色库内再次打开动作、定位/添加素材到画布、直接打开普通角色库等入口。

项目创作资产补充相同的人物卡片直达入口，定位本项目人物并保留资源库背景；顶部“打开角色库”同样使用项目作用域。三类项目卡片的“解绑图”需二次确认，取消保留全部绑定；确认后人物移除全部参考图和头像设置，场景/道具移除主图关联，原文件与画布节点保留。确认期间切项目、关闭资源库、删除资产或替换图片后，不得继续解绑旧目标。提交时按既有门禁执行改动文件定向 ESLint；测试、类型检查、构建与桌面验收未执行。

在图像、视频等提示词中打开 `@ → 引用资产`：全局弹框左侧应显示全部资产、人物/场景/道具、导入文件与外部文件夹，导航不提供新建/移除/复制/粘贴管理。首次使用即加载全局创作资产；分类搜索可匹配名称、简介及领域字段，文件夹与标签组合过滤和增量加载仍有效。场景/道具插入 `@drama{global/...}`；人物按原流程直接引用或继续选择具体参考图、拼图、动作和声音，原项目光标位置不变；普通文件仍插入 `@asset`。音频节点的创作分类只列出有可用声音的人物。同名项目/全局资产不得混用，关闭与 Esc 应返回编辑器；目录离线、扫描截断或全局库失败时显示状态并可重试，移除后的目录回退到全部资产。补充窄窗、明暗主题与键盘 Tab/Enter/Esc 验收；已完成静态核对并编写候选回归用例，提交使用定向 ESLint 门禁，测试、类型检查、构建与桌面验收未执行。
