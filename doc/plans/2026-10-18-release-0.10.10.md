# v0.10.10 发布计划

执行日期：2026-10-18。基线 v0.10.9，主题「ToAPIs 接入与 ComfyUI 一键安装」。

## 范围

- 内置 ToAPIs、国内/国际站共享 Key 与入口切换；文本目录仅保留用户指定的 9 个型号。
- RunningHub 分站凭据、源图片模型映射、资源引用预览、菜单裁切、画布视野恢复与多连线交互修复。
- Windows ComfyUI 官方便携版安装；公开 GitHub 下载的超时加速见 [专项计划](./2026-10-18-github-download-fallback.md)。
- ComfyUI 视频保留到本地交付成功，支持暂停后续取；空视频框比例与提示词图标样式修复。
- 同步版本、四种语言介绍、站点和发布正文；修复已定位的发布测试类型问题。沿用 IndexedDB v22，无数据迁移和依赖升级。

## 发布状态

本地门禁通过，等待提交后的同一 SHA CI。用户已授权隔离源码副本 npm ci、npm run ci、cargo check --lib、GitHub 回退专项 Rust 测试与提交钩子；本文件仅记录实际完成的门禁，不将历史检查当作本次通过。

- 隔离源码副本 `npm ci`、`npm run ci` 通过：全仓 ESLint、应用及测试类型检查、473 个测试文件共 7027 项测试与生产构建成功。构建仍有分块体积及动态/静态混用导入提示，未修改依赖或调整门禁。
- `cargo test github_fallback::tests --lib --locked` 3 项通过；`cargo check --lib --locked` 通过。
- 补齐 ToAPIs 协议数组与组件测试类型，并同步上传取消信号的旧接线断言；未跳过测试或放宽检查。

推送后必须等同一提交前端及 Windows Rust CI 成功，再创建不可变标签 v0.10.10；发布工作流完成各平台与 Legacy 构建后公开。

## 桌面验收与回滚

1. ToAPIs 切换国内/国际站，Key 保留，模型菜单与当前站点目录一致；RunningHub 两站 Key 独立。
2. Windows 便携版安装选择新目录，检查取消、校验失败及国内加速；不修改原有 Python 或显卡驱动。
3. macOS/Windows 检查 9:16 空框、ComfyUI 视频回填、失败续取与再次生成保留旧任务；回归源图片生成。
4. 检查插件与导演台 GitHub 超时切源、取消、进度重置与校验失败停止；各平台安装、签名、首次启动及升级待实机验收。
