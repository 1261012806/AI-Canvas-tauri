# 创作资产包导入导出

状态：项目与全局入口已实现，待用户验收。提交时由既有钩子执行改动文件的定向 ESLint；本次未运行测试、类型检查、构建或桌面验收。

## 目标与范围

项目「创作资产」顶部控件统一使用 UI Kit 小尺寸，增加导入与导出。顶部导出当前项目全部人物、场景、道具，不受搜索和分类影响；卡片删除按钮前的导出图标只导出当前资产及其绑定媒体。专用 `.aicassets` 包包含白名单元数据、图片、声音及动作媒体，不含画布、对话、凭据或服务端绑定。顶部导入兼容单资产与多资产包，均作为新条目追加。分集沿用所属剧集的共享库与素材目录。

默认文件名为「项目名-资产.aicassets」，单项导出为「资产名-资产.aicassets」。后缀「资产」、导入导出窗口、进度、结果和新增按钮提示复用 i18n 的中英日韩词条；文件内容与扩展名不随语言变化。

全局人物、场景、道具复用同一资产包格式。各分类顶部导出当前类别的全部资产，不受搜索影响；卡片导出单项，导入按包内真实类型分发到三个全局库并追加新身份。搜索、上传、新增和导入导出放在标题行右侧，窄面板允许换行。

## 实施步骤

1. `services/dramaAssetTransferFormat.ts` 定义版本格式、媒体引用和白名单字段，校验数量、路径、重复身份、主素材指针及媒体闭包。重新分配卡片与嵌套成员身份，旧画布/文件引用降为标签，不自动绑定本机同 ID。回归放 `tests/services/dramaAssetTransferFormat.test.ts`。
2. `services/dramaAssetTransferService.ts` 与 `services/fs/dramaAssetArchive.ts` 只整理本次所需媒体，复用原生流式复制的摘要和归档能力；导入校验实际文件、大小和摘要，再建立新的本机文件身份。拒绝缺失媒体和损坏格式；不打包整个项目或全局文件夹。回归放 `tests/services/dramaAssetTransferService.test.ts`。
3. `store/store.dramaAssets.ts` 一次追加全部新资产，等待实际项目/剧集保存，不按名称合并。提交前检查项目与取消；保存启动后等待其结果，不因视图切换删除已引用文件。保存失败仅撤回本批条目，保留其他编辑；已尝试元数据提交的媒体保留以便恢复，不能误删部分持久化记录的文件。回归扩展 `tests/store/dramaAssets.test.ts`。
4. `components/DramaAssetsPanel.tsx` 和必要 `styles/panels.css` 接入小尺寸控件、进度和取消，导入/导出/上传互斥。关闭、切项目或取消只阻止后续步骤，现有原生压缩/解包阶段仍须等待结束；元数据保存阶段不提供取消。模块入口更新 `doc/角色与短剧资产模块.md`。
5. `components/assets/GlobalCreativeAssetsPanel.tsx` 接入全局分类及单项入口，复用传输服务的全局作用域。导入媒体写到全局受管目录的专属叶目录，索引不带项目归属；全局人物与场景/道具元数据跨两表在单事务中追加，成功后一次更新全局 Store，不借项目库中转。面板关闭或切分类阻止未提交结果，项目切换不改变全局归属。

## 关键边界

包内图片、音频和视频均用受限媒体标识；不信任源机器路径、资产索引 ID 或运行期 URL。人物主图、头像、主音色以及动作素材指针一致重映射；RefMod 与方舟虚拟人像是外部环境绑定，不作为可迁移本地媒体自动启用。临时目录随机隔离，失败只清理本次所有的暂存目录，不清理共用素材。

项目主图身份沿用 `assetId/relativePath`；解绑、换图和主参考切换同步清除或更新身份，避免显示的新图与存储的旧图分叉。导出为卡片分配包内身份，兼容旧库跨类别同 ID；导入不继承源角色库的手动排序。新增索引使用全新身份，提交前回收仅匹配本轮 ID 与路径的记录。导入期间资产列表不可编辑，关闭与进度区仍可操作。

全局导出不解析项目节点；全局导入不要求打开项目，不创建项目或写项目库。场景/道具主图使用 `imageAssetId/imageRelativePath`，人物图声动作使用新全局媒体身份，均去掉源节点与项目路径。包内原类型不会因当前分类而改变；保存冲突或事务失败整批不入库，保留已有条目。全局媒体在元数据提交开始后保留，避免迟到取消或失败误删被引用文件。

## 用户验收

在 Tauri 桌面端准备人物多参考图、头像、声音、动作图片/GIF/视频及场景、道具主图。导出后切到另一项目导入，确认数量、简介、主素材和播放一致；同名资产追加且不覆盖，导入条目不定位或隐藏源项目节点。重启检查持久化，分集间检查共享库及素材归属。

分别使用顶部与卡片导出，检查默认文件名是项目名或资产名并带当前语言的资产后缀；单资产包导入只新增一项，媒体只含所选条目绑定的文件。切换中英日韩，核对文件选择窗口、图标提示、进度和结果文本；悬浮及点击卡片导出图标不打开角色库，导出期间重复点击不产生并发操作。

全局入口逐一回归人物、场景、道具：搜索后顶部仍导出整类，单卡只导出一项；无当前项目时也可导入导出。用混合类型项目包导入全局，检查条目进入真实分类，图声动作可预览，重启后仍存在；再导出全局包导入项目，确认没有源项目节点关联。同名导入不覆盖；失败、取消、关闭面板与切分类不产生半批元数据，切项目不把全局文件写到项目目录。检查标题行右侧布局及窄面板换行、深浅主题。

回归取消文件选择、素材缺失、错误格式/未来版本、非法路径、重复成员、摘要不符、保存失败、导入期间关闭/切项目，以及小窗口和深浅主题。原生压缩中取消应阻止后续提交，保存已开始后关闭面板应保持原项目的已接受保存，不写入新项目。确认只导出创作资产，不带整个项目、其他全局素材或外部绑定。
