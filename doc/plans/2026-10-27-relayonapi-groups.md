# 万象 API 分组连接

## 范围与状态

已实现分组管理：六个官方可见分组按独立连接保存 Key 和模型，统一入口汇总显示；保留旧连接身份，允许明确指定分组。模型候选取应用适配清单、Key 模型目录和公开分组目录的交集；公开目录请求不附带 Key，目录可见不代表实际调用权限。当前公开目录中 default 没有已适配模型。配置分享保留分组但不携带凭据。

同组已有多条连接时保留各自身份，单组删除只清理对应连接；待恢复任务仍按原连接读取当前 Key，不自动重投。用户主动更换 Key 后，旧任务是否可查询由平台决定。

实现已完成，自动化检查、桌面验收和付费调用均未执行。

## 桌面验收

1. 打开设置的 API Key 页面，添加万象 API，检查六组独立输入 Key 和默认候选；`default` 没有已适配候选时应明确显示。模型均不自动勾选。
2. 分别为图片和视频分组填写各自的 Key 并拉取目录，选择模型保存；节点、对话及 MCP 的模型选择应显示对应组，按选中连接调用。权限和计费以平台为准。
3. 有旧万象连接时确认其最初显示未指定分组，手动指定后连接 ID、Key 和已保存模型仍在；与已存在同组连接并存，不覆盖。编辑某组时验证高级参数和自定义协议不被覆盖。
4. 断网或使用无效 Key 拉取目录，应显示错误并保留已有候选和选择；单组删除不影响旧连接或其他组，统一入口删除需确认。复制和导出的配置不能包含 Key。
5. 对已有待取回任务验证原连接及原任务身份仍保留；恢复只查询，不创建新任务。若 Key 已更换，查询结果以平台权限为准。

回滚可撤销本批代码；现有配置和待恢复任务不应主动删除。
