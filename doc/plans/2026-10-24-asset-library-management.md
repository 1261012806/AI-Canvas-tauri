# 素材库管理补齐

目标：补齐用户确认的六项能力，在项目/剧集与全局之间保留明确的资产身份、引用和文件授权边界。

## 范围与设计

1. 创作资产多选：按 kind + id 选择，筛选变化清理不可见选择；批量导出所选条目、复制到全局/项目，复用既有业务 Action 和操作取消守卫。
2. 搜索与排序：共用人物别名/领域字段匹配规则；创作列表提供名称、创建时间、更新时间及升降序，不改变角色栏的手动顺序。
3. 资产包导入：在正式落盘前预览分类、媒体体积及同名提醒，选择条目后只迁移关联媒体；保持包校验、全新身份和追加语义。完成后能查看本次导入。错误显示资产与媒体项，不暴露路径。
4. 使用位置：按精确资产/文件身份查当前画布与持久化项目、创作资产，显示结果并定位；删除前展示影响，不以扫描失败推断未引用。
5. 失效修复：用户显式选择替代文件/目录，验证候选后重连，保留目录授权、身份与迁移边界；修复入口同时显示失效状态，存储健康接入真实外部目录。
6. 场景/道具多图：兼容旧单主图，每张参考图有独立身份，可选择主图与确切 @ 引用；项目、全局、导入导出、MCP 绑定保持一致。

界面沿用 UI Kit 小尺寸控件、现有素材卡片与预览，不新增依赖；中文为源语言，新增文案补中英日韩。

## Tauri 桌面验收

前置：备份一个含人物声音/动作、场景、道具、多张图片的测试项目，并准备全局资产、外部目录和 `.aicassets` 包。

- 多选筛选后的若干创作卡片，批量导出/复制；检查只处理所选条目，切项目、关面板和取消不写入错误作用域。
- 用人物别名、声音描述、场景时间与氛围、道具所属人物搜索；与 @ 候选一致；切换排序和升降序，角色栏手动顺序不变。
- 导入混合资产包，预览数量/大小/同名提示，取消不留下正式条目；仅选部分导入，点击“查看本次导入”能看见新项，保存重开仍存在。
- 查询文件和资产的使用位置，跳转到对应项目/节点；删除前显示实际影响；读取失败阻止危险结论，不显示“未使用”。
- 移走外部目录或测试文件，检查失效提示；选择正确的新位置重连，多匹配或内容不一致不能静默替换；关闭重开保留修复。
- 给场景/道具添加多图，设置主图并通过 @ 指定一张；更换主图不替换已有精确引用，删除所选图后明确提示失效。回归项目/全局互导、剧集共享、MCP 追加与重启。
- 回归窄面板、深浅主题、中英日韩和键盘操作；未授权付费生成不作验收步骤。

主文档：[角色与短剧资产](../角色与短剧资产模块.md)；文件修复边界归[文件与存储](../文件与存储模块.md)。

## 实现边界

- 创作列表排序偏好持久化，角色栏的手动顺序保持独立；筛选和作用域变化清理多选，批量只处理当前可见选择。
- 预览前完整校验包媒体，会额外占用一份整包暂存空间；仅所选依赖复制入正式目录。原生文件操作取消须等待当前调用结束，已接受的保存不会被迟到取消清理。
- 全局到项目复制复用资产包媒体落盘与提交边界，为图片、声音、动作建立新项目身份；包格式不携带源节点、远端绑定或凭据。同名条目追加副本，不覆盖。
- 单图引用固定到具体参考图，改变主图不会改写已有引用；删除所选图后明确失败，不用其他图代替。
- 失效重连复用有界摘要、原生文件授权、索引与媒体迁移日志；无旧摘要时只显示元数据匹配，必须逐项确认。详细范围见[使用位置与失效修复](./2026-10-24-asset-usage-repair.md)。
