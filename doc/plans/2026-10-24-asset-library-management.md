## 作用域、分类与引用

全局人物复用 `globalCharacters` 的 ID、参考图、声音和动作，不创建第二套记录；全局场景／道具使用 `globalDramaAssets`。固定分类是业务入口，与导入文件、外部目录分开。普通目录不自动分类或迁移，既有文件创建卡片不改变文件列表。删除卡片保留共用媒体；文件删除仍经文件菜单。

图片先固化到全局受管目录，再保存稳定素材身份。场景／道具主图用 `imageAssetId/imageRelativePath`，人物图声动作保留对应全局媒体身份，剥离项目节点与源项目路径。全局操作不借项目库中转；项目分集以所属剧集的 `seriesOwnerId` 共用业务库和素材目录。跨库复制建立独立副本，后续编辑不自动同步。

人物卡片主体（图、名称、简介及空白）或聚焦后 Enter／空格直接打开对应范围的角色界面，声音／动作按钮分别定位区域；卡片操作不冒泡打开角色库。资源库留在背景，关闭／Esc 只关闭当前弹层，返回保留分类和滚动；明确定位画布才关闭资源库。覆盖整页、弹窗与抽屉模式。

全局卡片无“解绑图”，可上传替换或在角色参考图中管理；项目卡片解绑需二次确认，取消不变，确认人物解绑移除全部参考图和头像设置，场景／道具清除图片关联，保留声音、动作、节点和文件。确认期间切项目、关资源库、删资产或换图后拒绝旧目标提交。

`@ → 引用资产` 的全局弹框只浏览和选择，复用分类、导入文件、外部目录，不提供新建／移除／复制／粘贴管理。首次使用加载创作元数据；文件由目录、标签与搜索组合过滤，创作分类按名称、简介及领域字段搜索。全局条目使用 `@drama{global/...}`，人物可下钻到具体图、拼图、动作和声音，普通文件仍用 `@asset`；光标位置和旧 `global/` 引用保持兼容。音频节点只列有可用声音的人物，同名或同 ID 的项目／全局项不混用。离线、扫描截断和加载失败可见且可重试，目录移除后回到全部资产。

## 多选、搜索、多图与修复

- 按 kind + id 选择可见创作卡片，支持导出所选和复制到项目／全局；筛选、搜索、项目或本次导入视图变化后清理选择。业务写入复用 Store Action 与取消／过期守卫。
- 项目／全局／@ 共用别名、人物声音／动作、场景时间氛围和道具所属人物等搜索。名称、创建时间、更新时间及升降序保存为创作列表偏好，不改变角色栏手动顺序。
- 场景／道具最多 32 张有独立 ID、标题、说明的参考图，旧单主图归一化兼容，显式清空不补旧图。单图 @ 固定具体参考图 ID，换主图不替换既有引用，删指定图明确失效，不换其他图兜底。项目／全局保存、资产包和 MCP 共用该语义。
- 文件和创作卡片共用使用位置查询，叠加当前未保存画布和持久化引用；删除／清空先展示影响，读取失败不按未使用处理，确认前复核变化。失效重连有旧摘要时严格核对，无摘要只标元数据匹配并逐项确认，多匹配不猜测。权限、迁移日志和旧路径保护及异常验收归[使用位置与失效修复](./2026-10-24-asset-usage-repair.md)，不扩宽路径授权。

## 资产包合同与提交边界

项目顶部导出全部创作资产，不受分类／搜索影响；全局顶部导出当前分类全部资产，不受搜索影响。卡片导出单项，多选导出所选集合。包只含目标资产及依赖图片、声音和动作媒体，不打包整个项目或全局目录，不带画布、对话、凭据或服务端绑定。RefMod／方舟虚拟人像属于外部环境身份，不自动作为可迁移本地媒体启用。

默认文件名为“项目名或资产名-资产.aicassets”，后缀文字及窗口、提示、进度和结果随中英日韩切换，文件内容与扩展名不变。导入兼容单项和混合包，按包内真实分类追加新身份，不因当前页签改类型、不按同名覆盖、不继承源角色手动排序，也不把源画布节点定位或隐藏。

包先完整校验版本、字段白名单、数量、受限媒体路径、重复身份、主素材指针、媒体闭包及实际大小／摘要，再预览分类、媒体体积和同名提醒。完整校验占用一份整包暂存空间；用户仅选部分时只迁移所选依赖。错误定位到资产和具体参考图／声音／动作，不暴露本机原生路径。混合包完成后可通过“查看本次导入”查看新卡片。

导入为卡片、嵌套图声动作及媒体索引重新分配身份，主图／头像／主音色／动作指针一致重映射，兼容旧库跨类别同 ID；不信任源机器路径、文件索引 ID 或运行期 URL，不自动绑定本机同 ID。项目主图沿 `assetId/relativePath`；换图、解绑和主参考切换同步更新或清除身份，避免显示与存储分叉。带武器角色导出／选择依赖由[武器专项](./2026-10-28-character-weapons.md)规定。

项目导入先校验和复制媒体，再一次追加卡片并等待实际项目／剧集保存。关闭、切项目或取消只阻止未提交步骤；保存已开始就等待结果，已接受的保存仍属原项目，不因视图切换清除已引用文件。保存失败只撤回本批条目并保留其他编辑；已尝试元数据提交的媒体保留供恢复，不能误删部分持久化记录使用的文件。

全局导入不要求当前项目，不创建项目或写项目库，也不解析项目节点。媒体写入全局受管目录的独立叶目录，索引无项目归属；人物与场景／道具跨两表在单个 IndexedDB 事务中追加，成功后一次更新 Store。事务冲突整批不入库且保留旧库。元数据提交开始后保留本批媒体，避免迟到取消／失败误清理被引用文件；切项目不改变全局归属。

上传、导入和导出互斥，导入期间列表不可编辑，关闭和进度仍可操作，元数据保存阶段不提供取消。原生压缩／解包不能即时中断，须等本次调用结束再阻止后续提交。临时目录随机隔离，提交前回收仅匹配本轮 ID 与路径的索引、暂存；不删除共用素材或其他操作文件。

2. 在整页、弹窗及抽屉分别点击人物主体、声音／动作、复制／编辑／上传／删除；只有主体或明确入口打开角色层，资源库不露启动页。Esc 逐层关闭并回原分类／滚动，定位画布才离开资源库。全局无解绑图，项目解绑确认取消不变；目标变化后旧确认失效。
3. 节点 @ 全局导航检查完整分类／目录和只读管理边界，搜索、标签、文件夹、增量加载组合有效。图像／视频／音频分别引用人物图声动作与场景／道具；音频分类仅有声音人物，同名项目与全局身份隔离。冷加载、离线、截断、失败重试及目录移除回退均有状态。
4. 筛选后多选卡片批量导出／复制，仅处理所选；改分类、搜索、项目或导入视图后不残留旧选择。按别名和声音／动作／时间氛围／所属人物搜索，与 @ 一致；排序重开保留，角色栏手动顺序不变。
5. 项目顶部、全局类别顶部、单卡与多选分别导出。搜索后项目仍导出整库、全局仍导出整类；单卡只含自身及必需依赖，声音／动作可播放，包不带其他目录、画布、对话或环境绑定。导出图标不打开角色库，重复操作不并发。
6. 切换中英日韩检查默认项目名／资产名与资产后缀、窗口、图标、进度和结果。文件内容和扩展名一致；深浅主题、窄窗换行及键盘操作可用。
7. 混合包预览分类、体积和同名提醒；取消不留正式条目，仅选部分只入所选依赖，“查看本次导入”仅看新项。单项包仅追加目标及必需依赖，同名不覆盖；重启及整剧分集间检查主图、头像、主音色、动作、文件归属和新 ID。
8. 无项目时全局导入；项目包导入全局再导出到另一项目，真实分类、图声动作及重启均正确，不保留源节点定位／隐藏关系。两个副本分别编辑保持独立，全局导入期间切项目不写项目目录。

10. 给场景／道具追加多图、设主图、@ 精确一张，再换主图，旧引用仍指原图；删除原图明确失效。回归旧单主图、显式清空、项目／全局互导、剧集共享、MCP 追加和重启。

## 回退与资料

回退界面／工具实现时保留既有全局角色表、全局场景／道具记录与媒体。`globalDramaAssets` 在 v23 引入，已经升级的数据库不能直接由 schema v22 安装包打开；不降 schema、不清库，当前真实版本以 `indexedDb/schema.ts` 为准。旧版本兼容须另行准备。撤销资产包代码不自动撤销用户已导入的卡片／文件，也不清理共用媒体；操作前保留项目归档。包内新增可选字段的旧客户端兼容及带武器资料的团队版本要求见武器专项。

当前职责见[角色与短剧资产](../角色与短剧资产模块.md)，媒体迁移、文件授权及存储健康见[文件与存储](../文件与存储模块.md)。素材使用位置与失效修复保留独立专项，本集清单与 S3 自动同步后续阶段不归本资产包实施范围。
