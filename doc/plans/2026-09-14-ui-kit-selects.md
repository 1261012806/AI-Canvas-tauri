# 原生下拉框统一使用 UI Kit

## 职责与状态

2026-09-14 已将 26 个业务文件的 69 处可见原生下拉迁移到共享 `Select`，样式预览同步使用真实组件。原扫描 28 个组件文件共 71 处原生 select；共享组件内部保留隐藏原生表单选项，不把它当作可见控件重复改造。

## 源码入口

- `src/components/shared/Select.tsx`：选项解析、UI Kit 菜单、表单语义、Portal、视口定位与键盘处理。
- `src/styles/ui-kit.css`、`src/components/styleGuide/StyleGuideSections.tsx`：共享样式与真实组件示例。
- 业务调用分布于节点弹窗、设置、角色/插件表单、画布圆环和视频剪辑；对应组件回归包含 `tests/components/mcpControlSettings.test.ts` 等文件。

## 已实施的交互边界

- 保留原 value、选项子树、option/optgroup、分组禁用、默认值与显式空值；声明式选项解析为统一菜单及隐藏原生表单选项。
- 保留角色弹窗 autoFocus、插件 required、MCP aria-describedby、字符串/数字 0，以及编辑开始/结束回调；不能机械替换标签而丢掉业务语义。
- 菜单 Portal 到 body，层级高于所属最高祖先并保持视口内，不被滚动容器或设置层裁剪；宿主外部点击判断将正确的 Portal 菜单视为内部交互。
- Escape 仅关闭下拉，不误关父弹窗；聚焦控件时隔离方向键、字母、删除、撤销等画布或图层快捷键。视频转场一次选择保留一次离散编辑/历史边界。
- 菜单按内容宽度展开并受视口最大宽度约束，不强制等于触发器宽度，避免窄按钮使中文竖排，超长内容仍可达。
- 复用主题变量与 UI Kit，不新增依赖、状态体系、Provider 或原生权限，不恢复全局原生控件样式补丁。
