# MCP 节点原文件读取与分块返回

日期：2026-10-26。状态：用户已确认下列 10 文件范围，源码与回归用例已实现；功能测试与实机验收待执行，未发版。后续提交请求按仓库规则由既有钩子执行定向 ESLint。

模块入口：[MCP 控制](../MCP控制模块.md)；文件边界见[文件与存储](../文件与存储模块.md)。本项为平台能力完善，复用现有 Registry、Policy、文件插件和瞬时 MCP 内容通道。

## 目标与选择

按当前项目的节点 ID 返回已落盘图片、视频或音频的原文件字节，不转码，不以缩略图或窗口截图代替原文件。客户端解码 Base64 并按偏移拼接，可保存得到原文件；不承诺任意聊天客户端提供下载按钮，也不自动写入客户端磁盘。

采用有界分块返回：整文件一次返回容易超过适配器接收预算并占用大量内存；新增下载 HTTP 服务会扩展鉴权和路由，不属于本次范围。沿用既有 MCP text 内容即可，不修改 stdio、HTTP 或内部 TCP 协议。

首期仅支持当前节点已落盘的主媒体。不自动请求远程 URL；远程、blob、内嵌数据或仅有缩略图时明确提示先将原文件保存或导入项目。不新增图片压缩预览、OCR、任意路径读取或完整项目导出。

## 调用合同

新增 `file_media_download`，effect 为 `read`，仅在 Tauri 桌面端的当前项目 MCP 控制会话可用。工具发现不得依赖 taskId；每次执行仍校验当前项目、会话和原生文件授权。

| 操作 | 输入 | 返回 |
|---|---|---|
| `begin` | `action`、`nodeId` | 不透明 `downloadId`、节点 ID、安全文件名、MIME、总字节数、`chunkBytes=262144`、失效时间 |
| `read` | `action`、`downloadId`、字节 `offset` | 同一文件的 Base64 原字节块、实际长度、块 SHA-256、`nextOffset`、`eof`；每块最多 256 KiB |
| `close` | `action`、`downloadId` | 关闭本次读取并回收文件句柄；不删除或修改原文件 |

示例：`begin(nodeId)` → 从 offset=0 开始逐块 read → 客户端核对每块 SHA-256 并解码拼接 → eof=true 后 close。无文件总大小的固定内存加载上限；偏移须为安全非负整数且不超出文件范围。同一块允许重读，以处理响应丢失；单下载的并发读明确返回忙碌，不能交叉修改文件位置。

完整文件内容仅放入 `mcpContent` 的 text JSON。消息、任务摘要及 `modelContent` 只含短状态，不保存 Base64、本地绝对路径或来源 URL；错误转换为固定脱敏类别。不会把 Base64 字符串当成模型可直接观看的图片。

## 源文件与生命周期

- 从宿主当前节点的 `imageUrl` / `videoUrl` / `audioUrl` 和一致的本地文件引用解析原文件；不接收模型提交的路径、URL 或目标保存位置，不回退到缩略图或陈旧 filePath。
- 原生读取经 `fileService.ts` → `services/fs/` 包装 → 既有文件插件 scope；拒绝目录、作为源文件的符号链接和路径遍历。授权、私有目录拒绝与窗口边界保持原状，不将词法前缀判断冒充真实路径授权。
- 文件句柄和本地路径只留宿主内存；绑定项目、对话、节点媒体来源和存储设置，读取前后复核。项目切换、节点删除或产物变化后旧下载失效，迟到结果不返回新项目。
- 每块检查文件大小和修改时间；异常、取消及失效时回收句柄。元数据检查只能发现通常的文件变化，不宣称抵抗同大小、同时间戳篡改的完整快照保证；块摘要用于客户端核对实际收到的字节。
- 最多保留 4 个活动、打开中或关闭未确认的下载，空闲 10 分钟失效；到达 eof 后仍允许必要的末块重读，随后由 close 或过期清理。原生关闭失败继续占用额度且明确报错，不承诺再次关闭一定能恢复，必要时重启应用回收运行时资源。关闭下载不会撤销其他业务操作。

### 实际静态核对

- 原文件读取使用固定块、短读补齐、显式 seek、大小/修改时间复核和幂等关闭；并发拒绝不关闭首个读取，关闭等待活动读取释放屏障，丢弃迟到结果。
- 下载会话绑定当前项目与精确 MCP 会话；节点来源及存储根变化后撤销下载 ID。取消已发生但新 read 尚未开始的请求，也清理本会话句柄，不借此关闭其他会话下载。
- 工具定义仅以只读 effect 注册，接收严格动作参数，不接收路径或 URL。直接工具名和 tools_call 的集成用例均检查大于通用文本裁剪阈值的内容仍只通过瞬时通道返回，消息/任务不保留字节正文或下载 ID。
- 独立只读审查未发现尚未处理的阻断问题；这不代表 TypeScript、ESLint、Vitest、原生权限或跨平台桌面验收已通过。实际执行检查结果仅限差异空白和严格 UTF-8 核对。

Tauri 桌面验收：

1. 准备 PNG/JPEG 图片、MP4 视频和音频素材，包含一个超过 256 KiB 的文件，并记录原文件字节数与 SHA-256；打开测试项目，刷新 MCP 目录。

3. 同一偏移重读结果应一致；尾块、offset 等于文件末尾、越界、负数、非整数及空文件应按合同返回或明确拒绝，不输出残缺成功。
4. 读取期间切换项目、删除节点、更换产物、修改/替换源文件或取消请求，旧下载应失效且句柄回收；跨会话下载 ID、目录、软链、不可访问文件及远程 URL 均不得绕过限制。
5. 验证活动下载上限、close、10 分钟失效、末块重读；检查聊天/任务和错误不含原文件 Base64、本地路径或来源 URL。分别回归 stdio、HTTP 和 tools_call，不为了验收重复调用生成模型。
