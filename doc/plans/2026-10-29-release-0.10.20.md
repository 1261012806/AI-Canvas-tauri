# v0.10.20 发布准备

日期：2026-10-29（Asia/Shanghai）。主题：**图片对比与生成流程**。以已公开的 v0.10.19 为比较基准；用户要求提交、推送并发布新版本，已确认发版文件范围和必要检查授权。

## 范围与状态

包含图片全屏滑动/左右对比其他节点和当前节点生成历史、视频参考角色连续选择、三项人设快捷指令新增人物质量提示词；同时纳入 v0.10.19 之后已提交的 RunningHub 动态媒体输入、逐节点图片批量、媒体结果保存、项目资产同步与恢复、图片全屏资源保护、MCP 和插件模型下载等修复。人设提示词中的参考背景、原布局与人像裁切要求可能与设定板多视图和浅色背景冲突，实际出图需要用户核对。

数据库维持 v26；项目云同步仍是手动项目资产同步，不共享全局资产或传播删除。关闭同步弹窗后应用运行期间继续同步；重启后可恢复已完成进度，但仍需人工核对，不承诺单文件字节续传。Windows Legacy 不含本地 ONNX 与自动更新；macOS 仅 Apple Silicon、临时签名且未经公证。

本次发版文件范围包括版本清单和锁文件、四份 README 版本徽章、站点与说明书、发布说明和工作流文案，以及本计划和索引；`tauri.conf.json` 只改版本。现有 Tauri 生成 schema 文件的工作区差异不纳入本次提交。

## 门禁与发布状态

用户授权后，本地 `npm run check` 通过（573 个测试文件、9838 项测试），Vite 生产构建通过；隔离工作区 `cargo check --lib` 通过，检查后的提交未更改 Rust 文件。发版提交 `6d9d371c` 的[同提交 CI](https://github.com/Tenney95/AI-Canvas-tauri/actions/runs/40827487423)前端与 Rust 均通过，标签 v0.10.20 已推送并绑定该提交。[Release 工作流](https://github.com/Tenney95/AI-Canvas-tauri/actions/runs/40828523938)的 Quality gate 通过，Windows、Linux、macOS Apple Silicon 三个平台构建已启动。发布构建在后台继续；安装包、签名、更新清单和 Release 是否公开尚未确认，以 GitHub 实际状态为准。标签不可覆盖，问题修复后另发补丁。

## 桌面验收

- 在 Tauri 中分别对比其他节点和本节点历史，检查滑动分割线、左右排版、名称、深浅主题、缩放和退出。
- 视频参考角色连续选择项目与全局角色，检查点击外部关闭和重复选择限制；分别生成三项人设快捷指令，核对背景、多视图和人物质量。
- 核对 RunningHub 工作流、受鉴权媒体下载、项目同步窗口关闭和重启后的恢复；真实 S3、付费模型调用、各平台安装和升级仍需目标环境验收。
- 升级前备份项目与应用数据；不将安装旧版视为数据库回退。用户恢复或回退时保留项目和媒体，不删除同步记录。
