# 大画布返回启动页与后台缩略图

主模块：[画布与项目](../画布与项目模块.md)。状态：已实现，待用户验收；未运行测试、性能采样或 Tauri 实机验收。

## 目标与依据

用户反馈节点和素材较多时点击左上角返回启动页会卡住，并要求评估保存、截图的子线程处理。静态阅读确认，返回流程在必要保存之前等待缩略图；已有截图 Worker 只承担绘制与编码，之前的 DOM 测量、SVG 曲线取样仍同步执行，失败后还会回退到全 DOM 克隆。尚无运行时性能数据，不能把这些可确认的阻塞路径当成已复现全部卡死原因。

## 实施范围

1. `src/services/projectSnapshotService.ts`、`projectSnapshotGeometry.ts`、`projectSnapshotWorker.ts`：复用已有 Worker，传入简化节点几何、连线、视口与少量可见媒体；不向 Worker 发送提示词或路径。父链计算防环并限制深度；媒体最多测量 24 个候选、提取 12 张，沿用 1.8 秒预算。取消全 DOM 截图降级，失败保留原缩略图。纯校验提取到 `projectSnapshotValidation.ts`，避免持久化入口加载 DOM 代码。
2. `src/services/indexedDbService.ts`：增加事务内读取最新项目后仅修改缩略图的入口，同时维护项目摘要；已删除项目不重建，不改正文、资产、更新时间等字段。
3. `src/store/store.projects.ts`：返回先让出一次绘制机会，并行启动可选截图与必要保存；后台 rAF 暂停时最多等待 100 毫秒继续。只有保存成功且画布引用仍匹配时才卸载。缩略图更新与项目正文共用串行队列，不使用捕获时的完整旧记录覆盖后续保存；同一不可变记录的并发保存复用在途结果，前后两次不同版本仍按顺序写入。捕获去重同时匹配数组引用和视口，迟到旧版本不能标记成新版本截图。
4. 对应回归：`tests/services/projectSnapshotService.test.ts`、`tests/services/indexedDbService.test.ts`、`tests/store/projects.test.ts`。覆盖待定截图不阻止返回、迟到截图保留新画布、删除不复活、保存失败保留画布、同版本并发合并和不同版本的串行顺序。

## 子线程边界

截图几何投影、离屏绘制和编码适合 Worker。DOM 和媒体元素只能在主线程访问，因此只做有界的可见媒体提取。项目正文保存保留主窗口、Tauri 文件授权与已有 IndexedDB 事务，避免新增一套文件能力和数据库生命周期；这不表示素材解析及 IndexedDB 输入克隆完全移出主线程。先消除返回前的重截图、旧记录回写和重复保存，剩余瓶颈需要用户授权实测后定位。

## 验收与回退

用户要求提交时，仅由提交钩子对暂存 TS/TSX 文件运行定向 ESLint，以实际提交结果为准；功能测试、类型检查、构建、性能采样及实机验收仍未运行。用户可在仓库根目录运行：

```powershell
npx vitest run tests/store/projects.test.ts tests/services/projectSnapshotService.test.ts tests/services/indexedDbService.test.ts
```

Tauri 桌面验收：准备包含长文本、多图片、视频和连线的项目，修改节点后点击左上角返回；界面应能及时绘制返回状态，保存成功进入启动页，重开后节点、内容和连线保持。缩略图可稍后更新，Worker 不可用时保留旧图。对比同一项目相同视口下返回交互延迟及主线程长任务，实际数字待采样。

异常回归：磁盘/数据库保存失败不能卸载；保存期间 MCP 新增节点或媒体回填应保留画布并提示重试；重复点击不重复导航；后台截图结束后不能回滚新编辑或重建已删除项目。回归普通项目切换、分集共享素材库及空画布缩略图清理。

回退本次缩略图、事务补丁、保存队列与返回流程差异即可，不涉及依赖、原生权限或数据库版本迁移。
