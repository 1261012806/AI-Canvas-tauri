# 大画布保存、截图与相邻操作性能

主模块：[画布与项目](../画布与项目模块.md)；关联：[文件与存储](../文件与存储模块.md)、[MCP 控制](../MCP控制模块.md)。

状态：两阶段代码已实现，待用户验收。首阶段已提交 `08b9804f`，当时提交钩子的定向 ESLint 通过；第二阶段提交时按仓库规则运行定向 ESLint。本轮未运行功能测试、类型检查、构建、性能采样或 Tauri 实机验收，新增回归用例不代表已经通过。

## 目标与依据

用户反馈节点和素材较多时返回启动页卡住，并要求评估子线程处理及类似瓶颈。静态阅读确认了截图等待、重复持久化、重复文件检查、无界恢复并发及重复全图扫描；尚无前后性能数据，不能认定这些路径解释了全部卡死原因，也不能承诺固定提速比例。

## 第一阶段：返回与项目缩略图

- `projectSnapshotService.ts` / `projectSnapshotGeometry.ts` / `projectSnapshotWorker.ts`：主线程投影必要几何并提取有限可见媒体，Worker 解析父链、裁剪视口、绘制简化连线并编码。最多测量 24 个媒体候选、提取 12 张，媒体总预算 1.8 秒、Worker 超时 8 秒；父链防环并限制深度。取消全节点 DOM 测量、SVG 曲线取样与全 DOM 克隆降级；Worker 不可用保留旧预览。Worker 不接收提示词或路径。
- `store.projects.ts`：返回先让出绘制机会，后台窗口最多等待 100 毫秒，再并行启动可选截图与必要保存；第二阶段调整为必要保存先启动，避免缓存预览补丁抢先入队。保存成功后复核项目、切换序号及画布引用，未保存的新内容不能被卸载。同一不可变记录的在途保存复用，后续版本按顺序落库。
- `indexedDbService.ts`：缩略图补丁在事务内读取最新记录，只更新图片及摘要；不回放旧正文、不修改更新时间、不重建已删除项目。捕获代次和画布引用阻止迟到结果覆盖新截图。

## 第二阶段：相邻瓶颈

| 范围与入口 | 已实现行为与边界 |
|---|---|
| 关窗 `App.tsx`；项目库 `Sidebar.tsx` | 关窗先启动必要保存，再并行处理可选预览，保留保存失败的重试/取消退出流程。项目库延迟更新预览，关闭面板或切换项目则取消尚未开始的采集，不再为更新预览完整保存一次正文。关窗不保证新预览赶在退出前完成。 |
| 空图及已有预览 `store.projects.ts` / `indexedDbService.ts` | 空画布通过补丁清除持久化预览；已有新鲜预览可直接补库而不重截图。先只更新内存、或上次补丁失败后再次请求持久化，都可重试，不能只凭内存已有/没有图片判断数据库已更新。 |
| 素材 `storageService.ts` | 同一次保存/加载中，规范化路径复用 `exists` Promise；不跨操作缓存文件状态或授权。写入内嵌媒体成功后刷新本次缓存；修复索引后清缓存再尝试恢复。加载外层最多同时恢复 4 个节点，节点内部保留原有引用并发，不能称为全局只有 4 次文件调用；索引刷新单独最多 4 路。 |
| 工作台 `episodeLayout.ts` / `EpisodeWorkbench.tsx` | 按节点身份、父子关系与镜头成员信息复用索引，组件只订阅计数摘要；排序与检查按操作时的最新节点读取。节点数组更新仍需 O(N) 轻量比较，变化的选中范围仍需重新统计，不是所有更新 O(1)。 |
| 复制/删除 `canvasHierarchy.ts` 及 Store、快捷键、菜单 | 一次父子索引配合防环队列收集后代，重叠根去重，避免逐层重复扫描全图。保留历史、动画、文件处理和项目边界；后代收集为 O(N+K)，整项操作成本还包含原有业务处理。 |
| MCP `mcpUiRuntimeService.ts` / `mcpCaptureEncoding.ts` / `mcpCaptureWorker.ts` | 只采集一次已按本次选项过滤的 DOM，再在 Worker 最多 4 档缩放/JPEG 编码。8 秒编码超时后终止 Worker，再对同一画布降级编码；超限不重新采集。相同尺寸、质量、脱敏选项复用；窗口内最多 1 个运行和 1 个排队，跨窗等待者最多 4 个，12 秒响应超时不释放仍未结束的底层采集名额。保持窗口白名单、默认脱敏和 2,600,000 字符图像预算。 |
| 归档 `projectTransferService.ts` / `projectArchiveSerialization.ts` / `projectArchiveSerializationWorker.ts` | 保存对话框前只读摘要取名，确认后重新读取完整项目、所属剧集及对话。固定 Worker 序列化 JSON，同时最多 1 项、60 秒超时，结束或失败均回收；Worker 不可用/失败明确拒绝并允许重试，不在主线程重新序列化大型正文。Rust 归档与路径检查沿用原流程。 |

## 子线程与安全边界

DOM 只能在所属窗口主线程访问，项目预览仅提取有界媒体，MCP 截图仍有一次主线程 DOM 克隆；MCP 兼容降级也有主线程绘制/编码成本。项目正文保留主窗口 Store、文件授权及 IndexedDB 事务，Worker 消息克隆、数据库输入克隆和原生 IPC 仍有开销，不能描述为全部保存或截图都移出主线程。

没有新增依赖、数据库版本迁移、权限放宽或独立文件执行入口。归档 Worker 仅整理宿主固定条目，MCP Worker 仅处理已采集位图；两者均不读取文件或网络。截图、归档正文和路径不新增到日志、消息或长期摘要。

## 用户验收

前置：使用 Tauri 桌面端，准备含长文本、多媒体、多连线、嵌套分组的普通项目，以及含至少两集和共享素材的剧集；保留一份备份。MCP 场景连接当前本地控制会话。以下均待执行：

1. 修改大画布后返回启动页并重开，再修改并关闭主窗口、重启。正文、节点、连线和共享资产应保留；返回状态可先绘制，预览可稍后更新。打开项目库、立即关闭或切换项目，迟到预览不能写错项目。清空画布再开项目库，重启后不应显示旧图。
2. 多节点共用图片、分镜参考图、角色图及音视频，保存后重开。移动/恢复素材后重试，应能重新观测文件；缺失或权限失败保留原有提示及原始节点，不能因缓存误报恢复。内嵌媒体仍应先落盘，不把大段数据 URL 存回数据库。
3. 在大量非镜头节点中编辑文本、拖动节点、切换选区，再使用逐镜工作台的数量、范围、检查和统一布局。镜头重命名及新增/移出组后应及时刷新，实际动作使用当前位置、参数与内容。
4. 复制或删除多层分组及重叠选区，再撤销/重做。后代不遗漏、不重复、不死循环，连线、媒体归属和一次撤销行为符合原操作；分别回归键盘与右键菜单。
5. MCP 请求主窗口及独立助手窗口截图，连续请求相同和不同尺寸/质量/脱敏选项。结果仍为可解码 JPEG；默认隐藏密码/API Key 等敏感元素。繁忙或超时明确失败，重试不无限增加采集；受控禁用 Worker 时仅复用本次过滤图像，不能返回另一脱敏选项的图片。
6. 在项目库取消导出应直接结束；确认导出大项目及剧集后，导入为新副本，逐集抽查中文、对话、记忆及素材。导出后台不可用、失败、并发繁忙或超时应明确提示，不生成成功结果、不改原项目；重试应可重新开始。

保存失败不能自动卸载画布；保存期间 MCP 新增节点或媒体回填，应保留当前画布并提示稍后重试。迟到预览不能回滚正文或重建已删除项目。回归普通项目切换、分集共享素材库及深浅主题。
