# ComfyUI RefMod 角色参考包接入

状态：代码已实现，待用户验收；未运行测试、类型检查、构建或实际生成。提交时由既有钩子运行本次暂存前端文件的定向 ESLint。

## 范围与边界

- 资源库新增「ComfyUI 角色」，记录所属服务、加载器格式、精确相对文件名与显示元数据；不复制模型，不索引任意本地路径。
- 通过已授权的 ComfyUI HTTP 通道读取节点定义及可选目录描述。原版、RefMods Lab、Francky 普通组合框加载器按各自 schema 适配；Fantastic 专有 Stack JSON 暂不改写，给出兼容提示。
- H3 本地视频工作流可选择、拖入多个参考包并绑定已有加载槽位。原版与 Francky 使用加载器声明的强度范围；Lab 强度仍由原工作流的组合节点控制。
- 服务 ID 与端点指纹共同绑定，禁止换服、删服或地址变更后静默使用同名文件。执行前重新读取目录，检查文件、槽位、链接和强度。
- 只修改提交用的工作流副本，不增加模型加载节点、不改连线。已有非空槽仅在用户明确选中该槽替换时变更。
- 槽位覆盖绑定工作流 ID 与原文件值；图更新或撤销跨模型时不移植旧覆盖授权。最终提交前再次核对实际服务器与源工作流，上传期间变更也拒绝提交。
- 角色卡可关联参考包，复用已有主参考图作为资源预览。绑定数组与资源元数据不保存服务 URL、模型二进制、绝对路径或凭据。
- 提示词下方不再展示独立 RefMod 大面板；入口统一在 `@ → ComfyUI`，分「工作流输入 / ComfyUI 角色」。工作流输入支持「全部 / 图片 / 视频 / 音乐 / 文本」筛选，音乐对应 audio，文本对应 prompt。
- 角色选择插入独立 `@refmod` 胶囊，包含脱敏的文件及槽位身份，强度与槽位在紧凑设置中编辑。提示词是该引用的唯一写入源，删除、复制、拖动、编辑器撤销与重新打开均沿用现有胶囊语义；资源库／拖入的手工绑定继续保存在节点字段中，不因删除其他胶囊而被清掉。
- 生成前从提示词及显式工作流输入中收集并移除 RefMod 标记，与手工绑定按槽位合并；相同配置去重、冲突失败关闭。RefMod 不计入普通图片编号或上传，其他模型入口拒绝未解析标记。

## 实施拆分

1. 公共领域类型与纯正规化；节点、配置、角色卡字段及 Store 写入入口。
2. 目录服务：受支持加载器注册表、只读 schema/元数据、精确文件名和服务指纹。
3. 工作流运行：已有加载器槽位映射、执行前校验、视频参数与批次指纹贯通。
4. 资源库、选择器、视频参数及专用 DOM 拖拽、角色卡关联。
5. 静态差异核对与针对性回归测试源码；更新所属模块文档，交付桌面验收步骤。

## 桌面验收

前置：本地 ComfyUI 安装相应 RefMod 插件，已有真实参考包及包含对应加载器的 API 工作流。

- 资源库刷新后展示插件实际识别的文件；名称、标签与角色关联保存并重启后恢复，无新增模型副本。
- 视频节点选多包、逐槽强度、移除绑定；仅显式指定的执行槽位变化，原工作流定义与连线保留。
- 从资源库拖到本地视频节点；错误类型、已占槽、多个加载器歧义、其他服务的同名文件均有明确提示。
- 删除参考包、删服务或修改地址后生成失败关闭；离线缓存明确标记为未验证/不可用，不伪装文件仍存在。
- Lab 不出现虚假的加载器强度；Fantastic 不自动修改 Stack JSON。
- 项目切换、异步目录请求返回、旧拖放负载和批次预检后改绑定不能写入错误项目或静默沿用旧物料。
- 深浅主题、长文件名、小窗口、空目录和未安装插件的提示及滚动可用。
- 打开视频提示词，确认原大面板消失；输入 @，ComfyUI 分类下的输入节点可依次按图片、视频、音乐、文本筛选，数量、鼠标选择与回车选择一致。
- 在「ComfyUI 角色」选择当前服务的参考包，明确目标槽位与强度后出现胶囊；双击修改后保存重开一致。删除胶囊后该引用不再参与生成，撤销可恢复；手工绑定保留且可从菜单中移除。
- 含重复胶囊不重复占槽；不同文件或强度争用同槽须提示冲突。切项目／切图期间迟到目录和插入请求不写回，工作流值区不嵌入 RefMod 胶囊。
- 将 RefMod 胶囊复制到图片、音频或普通文本入口，应提示仅支持本地 ComfyUI 视频，不将内部标记交给厂商。

回滚：移除新增 UI/服务入口与可选字段；既有工作流 JSON 及模型文件不受影响。新增元数据保留时不应影响未使用 RefMod 的生成路径。
