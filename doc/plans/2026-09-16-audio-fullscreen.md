# 音频节点全屏播放器

## 职责与状态

2026-09-16 已完成音频节点全屏播放、真实频谱及浏览器验收；Tauri asset 协议和真实格式的系统解码仍待桌面验证。主入口见[画布与项目模块](../画布与项目模块.md)，不改变生成、历史或持久化结构。

## 源码入口

- `src/components/nodes/AudioNode.tsx`：`ai-audio` / `source-audio` 双击入口、单击协调和节点播放交接。
- `src/components/shared/CanvasAudioPreview.tsx`：复用 Portal 全屏层，排序、切歌、播放器和键盘隔离。
- `src/hooks/useAudioSpectrum.ts`：真实 Web Audio 分析、主题颜色、绘图调度和资源释放。
- 回归：`tests/components/canvasAudioPreview.test.tsx`、`tests/hooks/useAudioSpectrum.test.ts` 及既有媒体全屏/LOD/节点交互测试。

## 已实施的交互与资源边界

- 双击有音频的生成/源节点打开占满应用窗口的播放器，Escape 或关闭退出；提供播放/暂停、可拖动进度、时间、音量和静音。
- 当前项目按 displayId 数值升序切歌，缺少编号排后，排除空音频及角色库收纳节点；首尾不循环，自然结束顺播，最后一曲停止。浏览位置不写画布选择、历史或持久化。
- 打开全屏时暂停节点并接续当前位置，关闭停止全屏；切歌释放旧媒体，项目切换、当前节点删除或来源变化均清理。播放和全屏使用既有 LOD pin 保活。
- 频谱来自实际播放信号，使用对数频率轴和 dB 刻度，禁止随机模拟；只有播放时创建分析图，暂停/隐藏停止动画，关闭断开节点并关闭 AudioContext。
- MediaElementSource 不能从原媒体元素解绑；跨域或分析失败时以不同 key 重建普通媒体元素，提示频谱不可用并保留基础播放，避免静音或重复绑定，不放宽安全配置。
- 单击播放短暂延迟以便双击取消，异步回调有失效序号，防止交接后旧节点重新出声。滑块与切歌键盘事件不能触发背景画布快捷键。
- 主题、按钮与频谱颜色复用 UI Kit 和 CSS 变量，不新增依赖、Rust 能力、安全权限或媒体文件改写。
