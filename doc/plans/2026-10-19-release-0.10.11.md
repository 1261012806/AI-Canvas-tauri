## 桌面验收

1. Windows / Linux 在深浅主题中切换最大化与还原，检查圆角空心图标、最小化、拖动和关闭；macOS 回归交通灯和全屏。
2. macOS 画布滚动、缩放、切换焦点和大图/视频预览，检查页面异常后的项目重开提示；确认保存后返回启动页再进入，节点和分集仍在。
3. 设置 → 外观 → 界面布局与底色，调整区域位置、底色关联、透明度与模糊（含 0），检查主窗口和独立窗口可读性。
4. 助手发送纯文字、单图和多图；在双窗口切换附件草稿，回归图片丢失、超限和视觉模型缺失的提示。导入有效/损坏 Skill 压缩包，核对入口与引用。
5. 新增分集填写名称、取消、留空及修改已有名称，检查未保存剧本不丢失。帮助中重开入口引导，核对保存位置不会自动改变。
6. ComfyUI 远端视频取回、暂停续取及格式错误提示；确认重试原任务不会重新计费。各平台安装、升级、签名与真实生成仍待用户验收。
