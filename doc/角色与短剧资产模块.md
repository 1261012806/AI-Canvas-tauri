## 文本提取与失败保护

人物、场景、道具提取共用 `dramaAssetExtract.ts` 的输入与结果校验。内置模板的「剧本正文」为空或只有占位符时，从当前文本节点可见的 `output` 补齐正文；面板与直接执行入口在补齐后追加项目提示词，分组执行沿用原有提示词组合。已有正文或显式 `@` 引用保持原样，仅连线不会自动注入上游文本。没有可用正文和引用时在请求前提示补充，不发送空剧本请求。

节点生成面板、直接执行和分组批量执行都先校验提取结果。无效 JSON、空条目、资产类别不符或请求失败时保留原 `output`，通过节点错误与失败历史显示原因，不写成功记录、不入库，也不把模型原文或「未规范化」说明写成正文。有效结果仍按原入口更新简介表并合并入库；工具条派生新节点的引用语义保持不变。

已实现。经授权，`dramaAssetExtract`、`nodeCriticalInteractions`、`batchExecute`、`seriesAssetExtractionService`、`presetNodeWorkflow`、`generationServiceReplicaLease` 六组 Vitest 共 256 项及本批 7 个 TypeScript 文件的定向 ESLint 通过；提交阶段由既有钩子再次执行定向 ESLint。`npm run typecheck`、`npm run test:typecheck` 均被本批未修改的已提交 `MentionEditor.tsx:140:86` 的 TS2339 阻断，没有全仓类型检查通过结论。未进行构建、桌面实机或真实模型调用。

Tauri 桌面验收：上传含正文的 `.md`／文本文件，保持提示词输入框为空，分别选择提取人物、场景、道具；预期实际请求包含正文，只有有效结果更新简介表与资产库。用可控测试接口分别返回空 `items`、错误类别、无效 JSON 或网络失败，预期原文、源文件身份和位置保持不变，显示独立错误且历史为失败；空节点不调用模型。再检查已有正文、工具条生成的新引用节点、分组批量执行与普通文本生成，确认不重复注入正文，不改变原有输出合同。

## 关键边界

- 创作资产面板支持按可见卡片多选、导出所选和跨作用域复制；切换分类、搜索、项目或本次导入视图会清理选择。项目/全局与 @ 共用别名、声音、动作和领域字段搜索；名称、创建时间、更新时间及升降序保存为独立创作列表偏好，不修改角色栏手动顺序。导入先完整校验暂存包，再预览分类、媒体体积及同名提醒，仅落盘所选资产及其媒体；混合包可通过“查看本次导入”集中查看新卡片。全局复制到项目时物化媒体为独立项目文件；资产包白名单不携带远端绑定。坏媒体错误定位具体资产与参考图/声音/动作项，不展示原生路径错误。六项管理能力及待验收步骤见[素材库管理补齐](./plans/2026-10-24-asset-library-management.md)。本次未运行测试，待用户验收。
- 场景/道具支持最多 32 张有独立 ID、标题和说明的参考图，主图保持顶层兼容投影。旧单图自动归一化，显式清空后不重新补出旧图；单图 @ 固定参考图身份，更换主图不替换既有引用，已删除或不可用的单图引用明确失败。角色声音/动作仍仅属于人物。多图覆盖项目保存/恢复、全局持久化、资产包、MCP 与预览，不另建媒体库。
- 文件和创作卡片共用使用位置弹窗，删除单项或清空分类前读取当前画布及持久化引用，读取失败不按未使用处理，确认前复核影响。查询及失效重连边界归[使用位置与失效修复](./plans/2026-10-24-asset-usage-repair.md)。

- 全局创作资产与项目资产分开管理；分集以剧集的 `seriesOwnerId` 共享资产，删除单集不删除共享素材。
- 全局人物、场景、道具支持同格式 `.aicassets` 包，与项目入口互通。顶部导出当前类别全部资产，不受搜索影响；卡片导出单项。导入保留包内真实分类并新增身份，不覆盖同名条目；文件直接进入全局受管目录，人物与场景/道具元数据跨两表原子追加，不要求当前项目，也不读写项目库。标题行右侧集中搜索、上传、新增及导入导出，使用小尺寸公用控件并支持窄面板换行。关闭或切分类阻止未提交结果，成功保存后迟到取消不漏更新全局状态。已实现，本次未运行测试，待用户验收；范围及桌面步骤见[创作资产包计划](./plans/2026-10-24-creative-asset-transfer.md)。
- 项目创作资产工具条使用 UI Kit 小尺寸控件，并提供 `.aicassets` 导入/导出。顶部导出全部项目人物、场景、道具及其图片、声音、动作媒体，不受当前分类/搜索影响；卡片上的导出图标仅导出该条目及绑定媒体，顶部导入兼容单项和多项包。默认文件名为「项目名或资产名-资产.aicassets」，资产后缀及新增交互文案使用中英日韩翻译。导入按全新身份追加，保留原库，不迁移源画布节点、服务端绑定或凭据。媒体先校验和落盘，再等待项目/剧集实际保存；取消、关闭和切项目阻止未提交结果，已开始保存的结果仍归原项目。原生压缩/解包阶段不能即时中断，失败清理及桌面验收见[创作资产包计划](./plans/2026-10-24-creative-asset-transfer.md)。本次未运行测试，待用户验收。
- 全局与项目创作资产的人物卡片主体直接打开对应作用域的角色库界面，并保留资源库背景；全局卡片的声音、动作按钮分别定位对应区域。全局人物、场景、道具卡片不提供“解绑图”，图片通过上传替换或角色参考图管理；项目创作资产保留节点绑图与解绑，解绑前需二次确认。人物解绑会清空全部参考图和头像设置，保留声音、动作、画布节点和文件；确认期间项目、资产或页面变化时不执行。
- 资源库「全局资产」的固定人物、场景、道具分类是业务入口，与导入文件及外部文件夹分开。人物沿用原 `globalCharacters` 记录、声音与动作；场景/道具保存在 IndexedDB v23 新增的 `globalDramaAssets`，主图使用 `imageAssetId/imageRelativePath`。图片先固化至全局受管目录，再存元数据，不保留项目节点依赖。既有文件可创建或追加至全局条目；普通目录不按名称自动分类，删除卡片保留共用媒体。详情及待验收范围见[全局创作资产计划](./plans/2026-10-23-global-creative-assets.md)。
- 提示词 `@ → 引用资产` 的全局弹框复用上述分类与文件夹导航，只提供浏览和选择；创作分类使用全局 `@drama` 身份，人物多图、声音与动作继续沿用原下钻选择，普通文件使用原 `@asset` 引用。目录、标签和搜索共同筛选文件；创作分类按名称、简介和领域信息查找，音频节点仍只提供有可用声音的人物。
- 资产变更走领域服务和 Store Action；Agent 入口继续校验项目上下文和 `asset_write` 策略。
- 参考图与声音元数据复用媒体和文件服务，模型适配与二进制落盘分别归对应模块。
- MCP / Agent 的 `drama_reference_image_add` 接受 `assetId + nodeId`，覆盖项目及全局的人物、场景和道具；`drama_voice_add` 仍只绑定人物声音。本机外部素材先通过 `file_import_media_to_canvas` 导入；工具只接受当前画布有效的对应媒体节点，不接受任意文件路径或 URL，沿用 `asset_write` 权限并在异步落盘前复核项目、取消和画布 revision。人物可指定用途与主素材；场景和道具追加独立参考图，可标注标题、说明并设置主图，返回精确单图引用。全局图片复用已有全局文件，来自项目的媒体需固化到全局目录；不保存项目节点 ID，源节点保持不变，不隐藏、不生成。全局三类 CRUD、`@` 候选/解析/预览与 MCP 库引用优先转换使用同一作用域和稳定 ID，声音/动作仍只属于人物。
- `canvas_create_nodes` 的项目 `ai-image` 可传已有的 `dramaAssetId`，整批写入前校验资产存在及节点类型，仅把 `dramaAssetId/dramaAssetKind` 关联写入节点；生成成功后通过既有 `syncDramaAssetImageFromNode` 回填库图，不在创建工具中额外调用资产写入或媒体模型。已有图片用 `drama_reference_image_add` 补绑；未知资产或非图像生成节点整批拒绝。
- MCP 创建/更新生成提示词时，能唯一匹配库内同一张可用图片的节点引用转为 `@drama`，多参考图固定到具体参考图 ID，保留 Picture 顺序；项目库优先于全局库，全局引用带 `global/` 前缀。相同名称不作为匹配依据；图像归属有歧义、库图缺失、分镜单格和非图片节点保留原节点协议，普通内部助手的显式节点引用不转换。库引用不自动连线，既有连线不自动删除。`canvas_query(detail=true)` 返回 `preferredMention`，资产查询返回 `imageReady` 和项目绑定节点 ID，客户端应先绑图再创建下游，不把只有文字的条目当 Picture 输入。无需新建持久化字段或复制媒体。
- 火山方舟虚拟人像库作为远端权威素材源，通过「设置 → API Key → 编辑火山方舟连接」弹窗内的独立可选配置启用，资产侧栏只负责查看与管理；项目名称默认 `default`。AK/SK 不进入普通配置或 IndexedDB，只保留 Rust 凭据条目引用。只有远端素材处于 `Active` 状态时才允许被 Seedance 生成入口消费。
- 有音频产物的生成音频、上传音频节点，右键提供「添加到角色库…」。复用角色添加弹窗的声音素材页，可试听并选择项目或全局已有角色、声音用途、台词及主音色；通过 `bindAudioNodeToCharacterVoice` 保存，沿用来源去重与资产持久化语义。弹窗的「添加后隐藏画布节点」默认勾选；仅保存成功且项目、源节点与画布 revision 仍有效时隐藏，取消勾选则保持显示。其他声音绑定入口不默认隐藏。
- 从画布添加动作素材（新建或追加）可选择添加后隐藏节点，默认勾选；动作缩略图右下角支持显示／隐藏切换。关联保存在来源项目节点的 `characterLibraryLinks` 中，按范围、角色、动作和素材 ID 区分，与参考图关联共存。
- 动作素材保存成功且项目、节点与 canvas revision 仍有效时才建立关联并隐藏；显隐复用画布历史与选中语义。移除素材、动作或角色时清理相应关联，无其他角色库关联的隐藏节点恢复显示。旧素材仅在当前画布有唯一媒体身份匹配时允许显隐，无对应节点或存在歧义时禁用按钮。
- 节点提示词的资产选择器在角色名旁提供「动作」入口，按动作、素材两级选择；有动作的单图或无图角色也可进入。动作引用保存角色、动作与素材 ID，读取库内素材，不随来源节点隐藏、删除或重新生成而改变；素材已删除或引用损坏时明确报错，不回落到主视觉。
- 动作图片与 GIF 进入参考图通道，视频进入视频生成的参考视频通道；文本模型、生图兼容入口与工作流文本输入沿用现有视频 URL 文本语义，不扩展模型能力。原参考图单选与合并引用保持兼容。
- 音频节点的资产选择器只列出库内有音频的角色，点击直接引用主音色；主音色不可用时取第一段有效音频。引用保存角色与声音片段 ID，读取库内音频，不随主音色切换或来源节点变化而替换；片段删除或引用损坏时明确报错。音频生成入口将其作为参考音频传给适配器，其他节点的图片与动作选择行为保持兼容。
- 视频生成节点的角色引用菜单在「动作」旁提供「声音」入口，列出角色全部声音片段并逐个插入指定声音的 @ 引用；只有声音的角色也可进入。失效片段禁用选择，引用复用既有角色声音协议与参考音频收集链路，实际支持范围由视频模型适配器决定。
- 视频参数的「参考角色」从角色库选图时，如该角色明确设置了可用主音色，同时保存参考音频；节点列表只展示一条角色记录并标示含主音色，移除角色时一起移除音频。普通连线图片没有角色声音，缺失或失效主音色不自动回落到其他片段；模型不支持参考音频时沿用生成前的能力校验，不绕过限制。
- 视频请求保留每个 @ 位置的角色 ID 与素材用途，合并显式素材、首尾帧和连线并去重后再编译编号与「角色参考对应」说明。同名角色使用本次请求内的角色序号区分；多图、多段声音和跨角色共用素材均保留归属。只重写系统生成的引用位置，不修改正文手写的编号；音色、台词、情绪分开标注，不自动把样本台词写入对白。归属信息仅在本次生成中使用，不增加持久化字段或向厂商发送未声明的接口字段。
- APIMart 带角色图片数组按适配器的首尾帧在前、参考图在后编译；独立首尾帧字段使用「首帧图片／尾帧图片」，不占参考图数组编号。本地工作流按本地素材数组编译角色引用，普通 ComfyUI／RunningHub 工作流保持既有 URL 提示词语义。实际外观与声音一致性仍取决于所选模型能力和真实生成结果。

- 创作资产支持按人物／场景／道具本地上传图片，也可给已有资产上传图片。桌面端复制到归属项目目录的 `Library/`，分集素材统一放在剧集目录；新资产默认以文件名命名，角色图片同步进入参考图库并设为主图。上传取消、复制失败或期间切换项目不会新增／绑定资产；浏览器模式仅保存图片数据，不承诺本地目录落盘。

## 界面入口与预览

创作资产同时可从资产大面板和 Tab 左侧资产库进入，角色库仍保留项目/全局范围。角色视频参考、动作视频和创作资产视频复用统一资源预览：封面按视口加载，点击后在所属面板内悬浮播放，切换项目/筛选或关闭面板清理旧播放器。预览不改变资产绑定或源文件；共享生命周期归[文件与存储](./文件与存储模块.md)。

提示词中的资产库／角色库与文件 @ 胶囊复用节点胶囊的悬浮预览卡片、120ms 延迟与交互抑制。项目／全局引用保持隔离，指定参考图、动作和声音按确切身份展示；失效引用不改为其他主图或主音色，无图资产显示简介。全部参考图以小网格预览至多四张并标注总数，文件图片仅悬停后解析 URL，不扫描目录。库引用不触发节点高亮或新增连线；切项目、滚动、按下及拖动时隐藏，异步文件结果不得重开旧浮窗。已实现，本次未运行测试，待 Tauri 验收；解析回归入口为 `tests/components/mentionEditorPreview.test.ts`，另回归节点／宫格悬浮、胶囊拖动、失效引用与明暗主题。

从资产库选择人物、场景和道具时统一插入 `@drama` 资产胶囊，显示资产名称与库来源；单张可用参考图也保存具体参考图 ID，不因绑定画布节点而变成数字节点胶囊。多图、动作和声音继续沿用原下钻选择。已有普通节点引用不自动猜测或迁移，需要从资产库重新选择。此调整已实现，本次未运行测试，待用户验收：在 Tauri 桌面分别选择项目／全局单图与多图资产，确认名称、缩略图和悬浮来源一致，保存重开后仍引用原参考图；回归新增或切换主图不替换已选单图、删除该参考图后提示失效，以及正常画布节点引用仍保留节点胶囊。

节点 @ 资产候选按完整项目库分类与搜索，不截取前 20 条。共用 `MentionPicker` 保留全部卡片位置，缩略图复用 `ViewportImage` 的可视区加载与离开后延迟卸载；分类、搜索或下钻内容变化时滚动复位，键盘高亮只滚动卡片列表。面板限制视口高度，超出的卡片在内部滚动，滚轮不继续传给画布。图片资源生命周期沿用既有回归，完整候选与滚动定位见 `mentionEditorSources.test.ts`、`mentionPicker.test.tsx`；本次未运行测试，大量资产滚动、窗口边缘、小窗口及深浅主题仍待桌面验收。

角色卡片的声音列表默认收起，通过下方工具栏的声音图标展开／收起；收起时停止试听并关闭音频绑定列表。切换角色、项目／全局范围或重新打开角色库时恢复收起状态。

底部角色栏支持拖拽排序：图标抬起跟手、相邻角色弹簧让位，释放后回落；边缘自动滚动并露出最终落点。轻点仍选中角色，拖拽不切换当前预览，Esc／指针取消不保存；支持 Alt + 左右键及系统减少动态效果。交互入口为 `character/CharacterDock.tsx`。

手动顺序通过 `DramaCharacter.libraryOrder` 保存，项目角色沿用项目／剧集共享资产保存，全局角色仅在 IndexedDB 单事务更新排序字段；不重存媒体、不改变角色修改时间。首次排序前保留原来的最近修改顺序，排序后新增角色追加在末尾，跨范围复制不继承来源顺序。搜索仅交换可见角色占用的槽位，隐藏角色保持原位；保存失败回退排序字段，保留同时进行的角色编辑，旧项目结果不回填到新项目。

角色参考图与声音定位复用历史记录的定位后放大回弹动画。声音条目在当前画布存在来源节点时提供显示／隐藏按钮；节点隐藏时不显示定位按钮，通过显示按钮恢复后才可定位。

视频节点的角色声音引用卡片右下角提供试听／暂停按钮，试听不插入引用；切换列表或关闭菜单停止播放。引用菜单的资产卡片统一为 9:11 比例，无可用图片、动作或声音的角色禁用引用。

用户步骤见[角色与动作库](../site/manual.html#character-library)和[@ 动作素材](../site/manual.html#character-action-mentions)。
